# vimuxx-claude-plugins

This is a marketplace of custom Claude plugins.

## Install

To install this marketplace in Claude Code:

```
/plugin marketplace add vimuxx/claude-plugins
```

## Plugins

### [web-search-mcp](https://github.com/vimuxx/web-search-mcp)

An alternative to built-in WebSearch and WebFetch tools. Search the web or fetch content from URLs.

To install this plugin:

```
/plugin install web-search-mcp@vimuxx-claude-plugins
```
